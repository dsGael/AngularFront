# Galeria de Fotos

Aplicacion Angular para administrar una galeria de fotos de forma dinamica.

## Funciones de la app

1. Mostrar fotos en un grid responsivo.
2. Agregar fotos nuevas con URL y titulo.
3. Dar likes a cada foto.
4. Eliminar fotos de la galeria.
5. Ver el total de likes acumulados.
6. Mantener los datos durante la sesion (sin base de datos).

## Uso rapido

1. Clic en "Agregar Foto".
2. Escribe URL y titulo.
3. Clic en "Agregar Foto" para guardarla.
4. Clic en el corazon para dar like.
5. Clic en la papelera para eliminar.

## Ejecutar

```bash
npm install
ng serve
```

Abrir en navegador: http://localhost:4200/galeria
